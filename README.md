# Just Professional Services – website

Website for JPS, a Perth handyman, carpentry, renovation and property maintenance business.

| Folder | What it is |
|---|---|
| `site/` | The website (Python / FastAPI) with quote requests, plan sign-ups and a staff admin area. See [site/README.md](site/README.md) to run it. |
| `wix-kit/` | Guide and copy-ready text for rebuilding the site in Wix. |

## Online

**https://nhuannguyen87.github.io/justprowa/** (GitHub Pages): all pages, rebuilt automatically on every push to `main` and daily. The forms are switched off for now; customers call or text Ben or Ash.

## Run it on a Mac

```bash
cd site
./run.sh
```
